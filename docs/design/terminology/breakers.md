# Breakers

| Term | Meaning | Code Examples |
|------|---------|---------------|
| **Aegis** | Lives-based breaker (3 lives). On bolt lost: `Fire(LoseLife(...))`. On bump: `Fire(SpeedBoost(...))`. Effects defined as `RootNode::Stamp(target, tree)` entries in `BreakerDefinition`. | `aegis.breaker.ron`, `RootNode::Stamp`, `Fire(LoseLife(...))` |
| **Chrono** | Time-penalty breaker (no lives). On bolt lost: `Fire(TimePenalty(...))`. On bump: speed boost. | `chrono.breaker.ron`, `Fire(TimePenalty(...))` |
| **Prism** | Multi-bolt breaker (no lives). On bolt lost: `Fire(TimePenalty(...))`. On perfect bump: `Fire(SpawnBolts(...))`. | `prism.breaker.ron`, `Fire(SpawnBolts(...))` |
| **PhantomBreaker** | Marker component on phantom breaker entities. Spawned via `Breaker::builder().phantom(BreakerPhantomParams { .. })`. Carries `Breaker` marker (visible to all `With<Breaker>` queries), `Lifespan`, and `PhantomFlicker`. Movement/dash/tilt input gated out via `Without<PhantomBreaker>`; bump input passes through; bolt-breaker collision participates normally. Despawned via `DespawnEntity` on lifespan expiry — NOT via `KillYourself<Breaker>` (which would emit `RunLost`). | `PhantomBreaker`, `breaker/components/core.rs`, `tick_phantom_breaker_lifespan` |
| **BreakerPhantomParams** | Builder params struct passed to `.phantom(...)`. Fields: `lifespan: f32`, `phantom_color_rgb: [f32; 3]`, `flicker_frequency: f32`, `flicker_min_alpha: f32`. Stashed in `OptionalBreakerData.phantom`; consumed by the terminal to insert `PhantomBreaker` + `Lifespan` + `PhantomFlicker`. | `BreakerPhantomParams`, `breaker/builder/core/types.rs` |
| **Lifespan** | Shared component (`remaining: f32`) in `shared::phantom`. Decremented each `FixedUpdate` tick by `tick_phantom_breaker_lifespan`. When `remaining <= 0`, the system emits `DespawnEntity`. Reused by phantom-bolt infra (TODO #2). | `Lifespan`, `shared/phantom/components.rs` |
| **PhantomFlicker** | Shared visual component (`frequency: f32`, `min_alpha: f32`) in `shared::phantom`. Drives alpha oscillation on the entity's `MeshMaterial2d<ColorMaterial>` via `tick_phantom_flicker` in `Update`. Only inserted on `Rendered` phantom breakers (headless skips it). | `PhantomFlicker`, `shared/phantom/components.rs`, `fx/systems/tick_phantom_flicker.rs` |
